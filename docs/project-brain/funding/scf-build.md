# Stellar Community Fund — Build Grant

**Status**: Superseded by Instawards grant
**SOW**: `docs/funding/sow/SOW_inital.md`

The SCF build grant was the original funding source for the TalkToStellar platform build. The scope covered the initial conversational PIX-to-Stellar product (WhatsApp bot, PIX on-ramp, Stellar wallet).

The current Instawards grant (`docs/funding/sow/SOW_instawards_submission_brl_usd_rail_20260520.md`) extends and supersedes the original SCF scope with additional deliverables (orchestration engine, payout routing, reconciliation).

**Key differences**:
- SCF: Basic PIX → Stellar flow
- Instawards: Full orchestration engine, payout routing, reconciliation, ops dashboard

Evidence for SCF deliverables is embedded in the main codebase. Instawards evidence is in `docs/insta-awards/docs/deliverable-1/evidence/`.
