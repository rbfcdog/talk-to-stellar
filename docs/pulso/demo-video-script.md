## Talking-points cheat sheet (keep it accurate)

- **Interface:** everything runs through **WhatsApp**; screens open from links the
  agent sends in chat.
- **On/off-ramp:** **live on mainnet** — receive via a **virtual account** (wire/ACH
  in), send dollars **out** (wire/ACH), all in **USDC**, via Bridge.
- **PIX (Brazil):** **not live yet** — in **compliance**, coming soon. Say "coming",
  don't demo it.
- **Yield (the focus):** **DeFindex** + **Blend** both **live on mainnet**. Money is
  auto-allocated and auto-redeemed when you spend. This is the longest beat.
- **Advanced:** more **Blend** markets being implemented; **Soroswap** integration
  just starting. Frame as "rolling out / wiring in", not finished.

## Recording notes

- Use **Live / Real** mode on the network toggle so balances look real (one
  toggle, top of the yield page).
- Portuguese on screen + English narration reads as "built for the market, told
  to the world" — that's fine.
- Don't show the access-password gate or any operator/detail panels — keep it
  customer-facing.
- If a live supply/withdraw is risky on camera, pre-fund and use a small amount
  (e.g. 1 USDC) so the ✓ confirmation is genuine.
- The on/off-ramp beat is fast (40s for both directions) — keep clicks crisp.
  Spend the saved time on the **yield** minute.
- Show the **WhatsApp → link → screen** hop at least once so the "all from chat"
  claim is obvious.
