# TalkToStellar 90-Second Demo Script

Purpose: a fast, marketable product demo covering login, conversion, PIX on-ramp, and PIX off-ramp.

Core message:

```text
TalkToStellar turns PIX into a simple dollar route: log in, convert, add money, withdraw, and get a clear receipt without touching blockchain complexity.
```

## 0:00-0:10 - Opening

Show: landing, chat, or login entry.

Say:

```text
TalkToStellar is a financial experience for Brazil where the user starts with PIX and ends with usable digital dollars, conversions, receipts, and payout flows, all without needing to understand wallets, trustlines, or blockchain.
```

## 0:10-0:30 - Login

Show: login or account entry screen.

Say:

```text
The first thing we optimized is access. The user can come from chat, WhatsApp, or web, log in, and continue the exact same financial session. Sensitive actions are protected by PIN or passkey, but the product feels like a normal banking app, not a crypto tool.
```

Point to:

```text
- simple login
- session continuity
- PIN/passkey confirmation
```

## 0:30-0:50 - Conversion

Show: conversion screen.

Say:

```text
Now I can convert balance in a guided flow. The product shows what I send, what I receive, the route, and the fee before confirmation. The important part is that Stellar is doing settlement work underneath, but the user only sees a clean money movement experience.
```

Point to:

```text
- amount
- source asset
- destination asset
- quote before PIN
- receipt after completion
```

## 0:50-1:10 - PIX On-Ramp

Show: PIX add-money/on-ramp screen.

Say:

```text
For adding money, PIX becomes the entry point. The user chooses how much should arrive, sees the final PIX amount, fee, and estimated savings upfront, then pays in their bank. Once confirmed, the balance is updated and the receipt is sent back to the same channel.
```

Point to:

```text
- receive amount
- final PIX amount
- visible fee
- savings
- confirmation status
```

## 1:10-1:30 - PIX Off-Ramp

Show: PIX withdraw/off-ramp screen.

Say:

```text
And the same rail works in reverse. The user can send balance out to PIX, review how much leaves the account and how much arrives in reais, confirm with PIN, and keep a receipt. This is the full loop: PIX in, conversion, PIX out, with transparent pricing and auditability.
```

Point to:

```text
- PIX key
- amount leaving balance
- amount arriving in BRL
- PIN confirmation
- completed receipt
```

## Closing Line

Say:

```text
The product promise is simple: make BRL-to-USD movement feel as easy as PIX, while keeping fees, confirmation, and receipts visible from end to end.
```

## If You Need To Cut Time

Use this 45-second version:

```text
TalkToStellar turns PIX into a simple dollar route. The user logs in from chat or web, confirms sensitive actions with PIN or passkey, converts balance with a clear quote, adds money through PIX with the final fee visible, and withdraws back to PIX with a receipt. The user never has to understand Stellar, trustlines, or blockchain operations. They just see what leaves, what arrives, what it costs, and proof that the operation happened.
```
