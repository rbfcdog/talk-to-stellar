# QA Session Logs

This folder is for scripted QA/testnet activity generated by:

```bash
npm --prefix backend run qa:wallet-activity -- --count 15
```

The script creates testnet wallets, funds them with Friendbot, sends XLM payments between them, stores chat-style messages/payment logs, and writes:

- `session-log.md`
- `session-log.csv`
- `wallets-public.json`

Do not present these rows as real user feedback. For grant/reviewer forms, keep real human sessions in a separate Notion section and only use these files as QA/testnet coverage evidence.
